# PR64 follow-up lexical-unit audit (Sol)

Base: clean HEAD `7b4573fe7131352749896f36c5fc04eb456d6671`, current run `2026-10-24-word-units-final-v5`, `reviewed.csv` 4,367 rows. Included lexical rows: 3,433 (`word` 2,209; `compound` 1,224). Original 11-column CSVs, annotations, and run were read only.

The eight approved endpoint corrections are in `pr64-followup-sol-decisions.json`. The original two are user-identified; the other six are surviving verb-stem boundaries before shared `ます`, `たい`, or `ない`. In `ohanashi_yokota_blog_001`, the old reading `フリ` for `降り` follows the `降る` dictionary entry. The record describes getting off a vehicle, for which `降りる` gives `オリ`; the full form is `降ります` / `オリマス`.

Structural screen: 923 lexical pairs have a shared final character; 413 have a shared suffix of two or more characters. For `compound`, 154 pairs have a shared final MeCab token sequence on both sides with some different leading material. This is a candidate profile only. A shared token sequence is often inside a technical term, name, numbered unit, or fixed compound, so it does not authorize shortening. Examples to keep: `三角橋／参宮橋` (whole place names; suffix-character chopping would be wrong), `皮下注射／筋肉注射` (named injection techniques, common `注射` is compound head), `ホットコーヒー／アイスコーヒー` (complete drink names), `悉皆調査／視界調査` (technical survey expressions), `禁煙席／喫煙席` (seat type; a character-only split would destroy `禁煙／喫煙`). These remain legitimate full lexical contrasts under the existing compound rule. `中水利用／注水利用` is individually different because researcher confirmation identifies the independent contrast as `中水／注水` and `利用` as surrounding shared usage context.

Stem screen: 47 lexical rows have a shared immediately following character and a matching final kana in the selected pair. A broader sweep across shared grammatical followers (`て`, `た`, `ます`, `たい`, `ない`, etc.) produced 63 candidates, only ten of which had a literal shared `て/た/ます/たい/ない` follower. Individual inspection yielded seven stem-only pairs including the user example. `syunkon_12835221992_013` already selects `誤って／謝って` [0,3) and is kept. Other endings include complete inflected verbs (`図って／諮って`, `驚いた／衰えた`), standalone nominal/adverbial forms (`怠り／お断り` before `なく`), a complete te-form (`やって／飲んで` before `ない`), and actual source notes comparing the selected full words (`みたい／いきたい`).

Reading gate: IPADIC constituent entries and context were inspected, but a standalone MeCab path or a chopped full-phrase reading is not treated as independent confirmation. New evidence should cite the original row and the relevant exact dictionary alternatives, retain original-audio/source uncertainty, and distinguish `confirmed` annotation status from actual audio verification. Same pronunciations are retained. No change is proposed to inclusion decisions, the 11-column originals, or past research runs.
